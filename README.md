# doit
A digital bullet journal for iOS

### Includes:
- **Todo list:** add and organize tasks into folders and set deadlines
- **Journal:** write journal entries like in a digital diary
- **Collections:** organize and rate your favorite movies, places, etc.
- **Habits:** track daily activities and view statistics
